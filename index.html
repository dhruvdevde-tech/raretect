ARCHITECTURE

Engineered specifically for sparse, extreme imbalance.

Generic anomaly detectors assume loud outliers. Raretect's 4-stage pipeline is tuned for subtle shifts spread across correlated multi-channel detectors.

01

Cross-Channel Feature Engineering

Calculates per-channel z-score deviations and row-wise dispersion so multi-channel signals don't hide in average feature metrics.

02

Outlier-Robust Preprocessing

Uses median imputation and RobustScaler (quantile-based scaling) so genuine detector background noise doesn't distort normalization.

03

Percentile Rank-Averaged Ensemble

Combines Isolation Forest and Robust Mahalanobis distance models via rank-averaging to eliminate single-model blind spots.

DEVELOPER QUICKSTART

Fit, score, and evaluate in 5 lines of Python.

Clean, scikit-learn compatible API designed for fast integration into existing research notebooks.

# 1. Import raretect pipeline and synthetic detector generator from raretect import Pipeline, generate_synthetic_detector_data # 2. Generate 5,000 events across 20 channels with 1% signal contamination df, labels = generate_synthetic_detector_data(n_samples=5000, n_features=20, contamination=0.01) # 3. Fit 4-stage pipeline pipe = Pipeline(contamination=0.01) pipe.fit(df) # 4. Compute anomaly scores & evaluate imbalanced metrics scores = pipe.score(df) metrics = pipe.evaluate(df, labels) print(metrics) # {'pr_auc': 0.770, 'roc_auc': 0.997, 'precision_at_90rec': 0.550}
# Configure custom model ensembling from raretect import Pipeline from raretect.models import IsolationForestModel, RobustMahalanobisModel pipe = Pipeline( contamination=0.005, models=[ IsolationForestModel(n_estimators=200), RobustMahalanobisModel() ] ) pipe.fit(X_train) predictions = pipe.predict(X_test, threshold=0.95)
# Generate comprehensive imbalanced evaluation report from raretect.metrics import print_rare_event_report report = print_rare_event_report( y_true=labels, y_scores=scores, target_recall=0.90 )
