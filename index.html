the problem

Generic anomaly detection breaks on scientific data.

Most ML tooling is built for fraud and security, where anomalies are loud. Detector data is different — the signal is faint, spread across correlated channels, and buried under legitimate outlier-heavy background.

Hand-rolled, every time

  • Notebook-by-notebook preprocessing, redone per dataset
  • StandardScaler distorted by the very outliers you want to find
  • Accuracy reported at 99% while missing every real event
  • One model, one blind spot — subtle multi-channel signals slip through

raretect's approach

  • One pipeline, fit to any tabular detector-style dataset
  • Robust scaling + imputation built for outlier-heavy data
  • PR-AUC, ROC-AUC, precision @ target recall — metrics that hold at 1%
  • Rank-averaged ensemble catches what a single model misses
how it works

Four stages, one call.

Every stage is inspectable and swappable — but the defaults are tuned for sparse, high-dimensional, imbalanced data out of the box.

01

Feature Engineer

Row-wise stats and per-channel z-score deviations, so signals spread across many channels don't hide in the average.

→
02

Preprocessor

Median imputation and robust scaling — built for data that's already full of outliers by definition.

→
03

Ensemble Model

IsolationForest + a lightweight autoencoder, rank-averaged, so no single model's blind spot dominates the score.

→
04

Evaluate

PR-AUC, ROC-AUC, and precision at your chosen operating recall — not accuracy, which lies at 1% contamination.

quickstart

From raw CSV to PR/ROC report in five lines.

No config files to start. Fit on your data, swap in your own model or feature module when you outgrow the defaults.

# pip install raretect
from raretect import Pipeline, generate_synthetic_detector_data

df, labels = generate_synthetic_detector_data(n_samples=5000, n_features=20)

pipe = Pipeline(contamination=0.01)
pipe.fit(df)

scores = pipe.score(df) # higher = more anomalous
metrics = pipe.evaluate(df, labels) # {'pr_auc': 0.77, 'roc_auc': 0.997, ...}
# Custom ensemble modeling
from raretect import Pipeline
from raretect.models import IsolationForestModel, AutoEncoderModel

pipe = Pipeline(
    contamination=0.005,
    models=[
        IsolationForestModel(n_estimators=200),
        AutoEncoderModel(hidden_dims=[32, 16, 32])
    ]
)
pipe.fit(X_train)
predictions = pipe.predict(X_test, threshold=0.95)
# Comprehensive rare-event evaluation report
from raretect.metrics import print_rare_event_report

report = print_rare_event_report(
    y_true=labels,
    y_scores=scores,
    target_recall=0.90
)
# Returns: PR-AUC: 0.770 | ROC-AUC: 0.997 | Precision @ 90% Recall: 0.550
